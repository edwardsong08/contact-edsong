# Project context

Personal website and web application inquiries for Edward Song at https://contact.edsong.xyz.

The site explains landing pages, custom websites, web applications, and larger platforms. Visitors can build a short project brief, open it in their email app or Gmail, or copy it. No inquiry content is submitted to this server or stored in a database. The visitor completes sending in their email provider.

Stack: Next.js App Router, React, TypeScript, locally bundled DM Sans and Instrument Serif fonts, plain CSS, standalone Docker image on port 3000. GET /api/health provides a minimal health endpoint.

Repository and verified deployment details are recorded in LOGS.md. No third-party analytics or external runtime assets are needed.
